# Agente observador

Leia `docs/POLITICA_EDITORIAL.md` e `docs/OPERACAO.md`. Execute `npm run audit:content` para inventariar o acervo antes de propor mudanças. Registre evidências, lacunas e próxima ação. Não publique sem revisão humana; não altere fontes originais externas.

Consulte fontes oficiais com `npm run monitor:sources`. Não interprete mudança de hash como anúncio: leia a página, verifique data, território e novidade concreta. Não exponha credenciais nem dados pessoais. Prepare correções em branch, com revisão e testes, sem merge automático. Permaneça silencioso quando não houver mudança útil.
